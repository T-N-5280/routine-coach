# Routine Coach（日常提醒小幫手）

[English](README.md) | [簡體中文](README.zh-CN.md) | 繁體中文（本文件）

一個語音引導、支援中文（大陸／台灣）雙版本的日常習慣提醒應用程式。完全以單一 HTML 檔案在瀏覽器中執行，用自然的語音帶你走完早上和晚上的日常，並支援跨裝置同步。

---

## 這是什麼

一個個人習慣輔助應用程式，具備以下功能：

- 依序引導你完成**早上**和**晚上**的日常習慣，配有視覺化倒數計時圓環
- 每個習慣開始時會**語音播報**（使用 Azure 自然語音，而非瀏覽器內建的機械音），並每 5 秒用「X分Y秒」的格式語音倒數
- 支援**引導序列**——一個習慣由多個帶計時的子步驟組成（例如伸展組合：前彎 → 休息 → 橫劈腿 → 休息，重複多次），每個子步驟都可以有自己的語音提示
- 可以為任意習慣設定**特定星期幾**才進行（例如洗衣服只在週六）
- 提供完整的**大陸中文／台灣中文**切換——不只是簡繁轉換，還包括真實的地區用詞差異（如拉伸/伸展、熄燈/關燈等）
- 透過使用者自訂的「同步碼」，藉助 Cloudflare KV 實現**跨裝置同步**
- 保留**本機版本歷史**，附真實的差異比對功能，可以清楚看到任兩個版本之間具體改了什麼，並一鍵恢復到舊版本
- 支援將整套習慣資料**匯入／匯出**為 JSON，方便備份或批次編輯

---

## 架構

這是一個刻意保持簡單的**靜態網站 + 一個小型後端代理**架構——沒有資料庫伺服器，沒有帳號系統，也沒有建置步驟。

```
┌─────────────────────────────────────────────────────────────┐
│  你的手機 / 電腦瀏覽器                                          │
│                                                                 │
│   index.html（整個應用程式——HTML + CSS + JS，單一檔案）        │
│     │                                                          │
│     ├── localStorage ─── 習慣資料、同步碼、版本歷史、          │
│     │                     語言偏好設定                          │
│     │                     （皆依裝置本機保存）                   │
│     │                                                          │
│     └── fetch() 請求發往 ↓                                      │
└─────────────────────────────┬───────────────────────────────┘
                               │
                               ▼
                 ┌───────────────────────────┐
                 │  Cloudflare Worker           │
                 │  (tts-proxy)                 │
                 │                              │
                 │  /            → 語音代理      │
                 │  /sync/save   → 寫入 KV       │
                 │  /sync/load   → 從 KV 讀取     │
                 └───────┬───────────┬──────────┘
                         │           │
                         ▼           ▼
              ┌────────────────┐  ┌─────────────────┐
              │ Azure Speech     │  │ Cloudflare KV     │
              │（自然語音）       │  │（跨裝置習慣資料儲存）│
              └────────────────┘  └─────────────────┘
```

**為什麼需要一個 Worker：** Azure 的語音合成 REST API 不允許瀏覽器 JavaScript 直接呼叫（CORS 限制）。這個 Worker 的唯一作用就是充當中間層——它保存真正的 Azure 金鑰（瀏覽器永遠看不到），並轉發請求。順便也承擔了跨裝置同步的後端功能，因為它本來就已經存在。

**為什麼沒有框架或建置步驟：** 整個專案的初衷就是保持單一檔案形式，方便隨時開啟、編輯、重新部署，不需要 npm、打包工具或本機開發伺服器。所有的介面、狀態管理、渲染邏輯，以及 Azure／同步／歷史記錄相關的程式碼，全都寫在 `index.html` 的一個 `<script>` 標籤裡。

## 檔案結構

| 檔案 | 作用 |
|---|---|
| `index.html` | 整個應用程式。只有前端程式碼，沒有伺服器端邏輯。 |
| `azure-tts-proxy-worker.js` | Cloudflare Worker 原始碼。負責代理 Azure 語音請求，並透過 KV 處理跨裝置同步。**目前尚未接入自動部署**——詳見下方「已知限制」部分。 |

## 資料都存在哪裡

| 資料 | 儲存位置 | 說明 |
|---|---|---|
| 習慣資料（早上/晚上日常） | 每台裝置的 `localStorage`，如果設定了同步碼，也會存入 Cloudflare KV | 本機副本相當於離線快取；如果啟用同步，KV 中的資料才是跨裝置的「真正版本」 |
| 語言偏好（大陸/台灣） | 僅存在 `localStorage` | 依裝置本機保存，不會同步 |
| 同步碼 | 僅存在 `localStorage` | 每台裝置各自記住自己連接的是哪個同步碼 |
| 版本歷史（最近 30 筆） | 僅存在 `localStorage` | **不會跨裝置同步**——每台裝置都有自己獨立的歷史記錄 |
| Azure API 金鑰 | Cloudflare Worker 的密鑰設定（僅限後台） | 完全不會出現在瀏覽器或本儲存庫的任何檔案中 |

## 從零開始建置

### 1. Worker（語音 + 同步後端）

1. 註冊一個免費的 Cloudflare 帳號。
2. Compute → Workers & Pages → Create Worker，將 `azure-tts-proxy-worker.js` 的內容貼上，點擊部署。
3. 在 Settings → Variables and Secrets 中新增：
   - `AZURE_KEY`（你的 Azure 語音資源金鑰，需標記為 **Secret**）
   - `AZURE_REGION`（例如 `eastasia`——必須與你 Azure 資源的實際區域一致）
4. 建立一個 KV 命名空間（Storage & Databases → KV → Create namespace）。
5. 將其綁定到 Worker：Settings → Bindings → Add → KV namespace → 變數名稱**必須精確寫成** `ROUTINES_KV`。
6. 記下 Worker 的網址（例如 `https://tts-proxy.你的子網域.workers.dev`）——這個地址需要和 `index.html` 中 `<script>` 頂部的 `PROXY_URL` 常數保持一致。

### 2. 應用程式本體

兩種方式擇一：

- **直接上傳**——Cloudflare Pages → Create → Upload assets → 拖入 `index.html`。之後檔案有更新時，需要手動重新上傳一次新的部署。
- **Git 自動部署**——Cloudflare Pages/Compute → Create → Connect to Git → 指向本儲存庫。建置指令留空，輸出目錄填儲存庫根目錄（`/` 或 `.`）。之後每次 push 都會自動部署。*（本儲存庫目前實際採用哪種方式，請以 Cloudflare 後台實際顯示為準。）*

### 3. 加到手機主畫面

在 Safari（iPhone）或 Chrome（Android）中開啟應用程式網址 → 分享/選單 → 「加入主畫面」。這樣會得到一個類似原生 App 的圖示，開啟時沒有瀏覽器網址列。

## 日常使用說明

- **編輯習慣：** 點擊應用程式底部的「編輯」。修改會自動保存（保存到 `localStorage`，如果已設定同步碼，也會同步到雲端）。
- **跨裝置同步：** 在「跨裝置同步」區域輸入任意同步碼（英文字母/數字/短橫線/底線，3–64 個字元），點擊「設定」完成連接。連接後需要手動選擇「從雲端拉取」或「推送到雲端」——**輸入同步碼本身不會自動進行任何方向的資料傳輸**，這是刻意設計，避免資料被靜默覆蓋。
- **查看歷史版本：** 「歷史版本」區域會自動記錄快照（有修改時大約每 3 分鐘記錄一次，避免頻繁打字時洗版），可以查看與目前版本的差異比對（用白話文描述改動內容），也可以恢復到任一歷史版本。
- **批次編輯／備份：** 「匯入 / 匯出」區域可以貼上完整的 JSON 習慣資料（格式見下方），或複製匯出目前的資料。

## 習慣資料 JSON 格式（用於匯入/匯出）

```json
{
  "morning": [
    { "name": "喝水", "seconds": 30, "days": [], "voice": "", "midway": "" },
    {
      "name": "伸展",
      "days": [1, 3, 5],
      "subSteps": [
        { "name": "前彎", "seconds": 30, "voice": "" },
        { "name": "休息", "seconds": 10, "voice": "" }
      ]
    }
  ],
  "night": []
}
```

- `days`：星期幾的數字陣列，`0` 表示週日，一直到 `6` 表示週六。空陣列 `[]` 表示每天都進行。
- 每個習慣要嘛是**單一計時**（有 `seconds` 欄位），要嘛是**引導序列**（有 `subSteps` 欄位，不帶最上層 `seconds`）——兩者不會同時存在。
- `voice`：可選，習慣/子步驟開始時播報的自訂語音內容。留空則預設播報習慣名稱。
- `midway`：可選，僅對時長超過 40 秒的單一計時習慣生效，在進行到一半時播報的提醒語。

## 已知限制／需要注意的地方

- **Worker 目前沒有接入 Git 自動部署。** 更新 `azure-tts-proxy-worker.js` 仍然需要手動把新程式碼貼到 Cloudflare 後台。這是刻意保留的手動步驟，因為讓 Worker 自動部署需要在儲存庫中加入 `wrangler.toml`/`wrangler.jsonc` 設定檔並寫明準確的 KV 命名空間 ID，一旦寫錯就有可能暫時導致語音或同步功能失效——之後有需要可以再著手處理。
- **同步沒有真正的身分驗證。** 同步碼本質上是一個共享密鑰，不是登入帳號——任何知道你同步碼的人都可以透過 Worker 的 `/sync/save` 和 `/sync/load` 介面讀取或覆蓋你的習慣資料。不要把真正的密碼用作同步碼，也不要把同步碼分享給別人。
- **同步遵循「後寫入覆蓋」原則，不做智慧合併。** 如果兩台裝置在完全離線的情況下同時修改了同一份資料，最後一個連線同步的裝置會覆蓋另一台的修改。在正常的個人單人使用情境下，這種情況基本不會遇到。
- **版本歷史是每台裝置各自本機保存的**，不會透過雲端同步。手機上的歷史記錄和電腦上的歷史記錄是相互獨立的，且都只保留最近 30 筆快照。
- **差異比對是依習慣名稱配對的，沒有穩定的唯一 ID。** 如果你在改動一個習慣的同時也重新命名了它，差異畫面會把它顯示成「刪除了一個習慣 + 新增了另一個習慣」，而不會識別成「重新命名」。
- **本應用程式會在 Azure 請求失敗時（離線、超出額度等），自動改用瀏覽器內建的 `speechSynthesis` 語音**——所以語音引導理論上不會完全沒聲音，但備用語音聽起來會明顯更機械化，不如 Azure 自然語音自然。
